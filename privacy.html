Privacy

Updated October 25, 2026.

Website inquiries

The contact form prepares a draft in your email application. It does not save submissions to the dashboard or send them automatically. If you send the draft, the information is shared through your email provider and received by Coastal Web Work’s to respond to your inquiry.

Hosting and fonts

Cloudflare hosts this website and may process technical request logs, including IP addresses. This version uses system fonts and does not request fonts from Google. No analytics or advertising tracking has been added to this version.

Cookies and browser storage

The public website does not set analytics or advertising cookies. Its animation and navigation preferences last only while the page is open. Dashboard preview records use local storage; signed-in dashboard tokens are held in memory and cleared when the page closes or reloads. Cloudflare and authentication services may process technical information needed to deliver and secure their services.

Dashboard records

The dashboard has a browser-local preview and an owner-only cloud workspace. Preview records remain in that browser’s local storage. When the owner signs in, records are stored in Supabase and protected by owner-only database access rules. The dashboard page itself is public; access to cloud records requires the authorized owner account.

Local records do not migrate automatically when signing in. Signing out clears cloud records from the current view, but does not delete saved cloud records or existing local preview records. Exported backups are separate files under your control; store them securely. Contact us about access, correction, or deletion requests.

AI assistance

AI assistance is enabled for the signed-in owner. When the owner asks an AI question, the question and selected saved workspace fields are sent through a server-side function to OpenAI. These may include business names, task and project descriptions, dates, statuses, and financial amounts, with up to the latest 100 records in each supported category.

Dedicated email, phone, website URL, and free-form notes fields are omitted from the workspace snapshot. Questions and included text fields are sent as entered, so avoid putting sensitive information in them. The server requests store: false; this does not guarantee zero provider retention. Provider processing and retention remain subject to their applicable terms and settings.

AI answers do not directly change records or send communications. Supported action commands prepare a local draft; a record is written only after the owner confirms it in the review form. API credentials stay in server-side settings and are not included in AI questions.
